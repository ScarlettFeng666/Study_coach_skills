# 复习流程与质量规则

本参考用于收集材料、分配时间、编写题库和回收学习报告。数据结构与构建方法以 [data-contract.md](data-contract.md) 为准；本文件不重复字段定义。

## 1. 建立可追溯的输入

首先区分当前任务：用户是在备考，还是在创建这个技能。首次完整备考对话先按 SKILL.md 的开场介绍流程、资料准备和最终刷题网页，再按“范围 → 课件 → 例题 → 本次学习时长”逐步补齐，每轮只问 1–2 个缺失问题；用户已经给出的内容直接提取。回传报告、继续学习或只剩最后 5 分钟时，直接接续当前任务，不重复完整开场。

创建一张简短的来源清单，至少记录名称、类型、实际读取范围、定位方式和使用限制。内部记录可详细，交付给学生的说明保持简短。

| 来源状态 | 可据此做什么 | 必须说明什么 |
| --- | --- | --- |
| 已读取且可核实 | 引用已读章节，支撑考点、答案和解析 | 文件名与真实页码／章节；只写能定位到的位置 |
| 用户转述或未核实 | 作为暂定范围、学生偏好或待核实说法 | “根据你的描述”“答案待核实”，不伪装成原文 |
| 通用知识补充 | 填补概念背景，生成明确标注的通用练习 | 属于补充，不能冒充老师的授课范围 |
| 无法读取／未提供 | 记录缺口，问一次是否有替代形式 | 不推测缺失正文，不声称已读取链接或附件 |

引用页码时区分 PDF 物理页与印刷页；不知道页码就用标题或章节。例题本身能证明它考过哪个概念，不能证明答案正确。学生填写过的选项、手写答案和旧错题记录不是答案键，必须对照课件或正式答案；没有答案的 past test 需要独立推导并标注推导状态。发现原答案错误时清楚指出并解释，不能为了顺从学生而沿用错误。

若材料缺失，说明能做的是“暂定范围的通用练习包”，优先覆盖用户明确的考点。若只拿到某一章，不把完整课程写成已覆盖。材料相互矛盾时记录双方位置，必要时向学生问一个聚焦问题；仍不明确的点不进入确定答案的计分题。

## 2. 从材料提取蓝图

建立考点列表，每个考点连接到来源、要求的能力和可测题型。能力可包括识记、理解、追踪执行、应用、解释和推导。保留课程中的符号与约定，避免用通用定义覆盖教师明确指定的定义。

明确的 study guide 限定范围，past test／quiz 校准风格、重点和难度，不能因某题出现在旧卷就自动加入当前范围。用户明确只要“guide 与 quiz 的交集”时遵从该限制；未作此限制时，guide 内尚未在旧卷出现的内容仍可能需要覆盖。行政信息、课程流程等是否排除取决于当前范围，不设全局“永不考”的规则。

优先级依次参考：明确考试范围／教师说明、代表性例题的分布、课件强调程度、学生已报告的困难。权重没有证据时采用均衡覆盖，标注为计划假设；不能从少量往年题推断出“本次必考”。

按正式考试的题型结构出题。例如编程考试有读代码、写代码和简答时，不因网页自动计分方便就全部改为概念单选；正式考试明确只有单选时，可以把 past quiz 简答转换成有足够条件的单选，并保留原考点。题干语言跟随考试，解释可用学生偏好的中文等语言。页面的简答题可容纳文本或代码作答，由学生依据评分要点自评；复杂图形、证明等不适合页面处理时，允许纸上完成并自评。

## 3. 用学习时间决定题量

“本次可学习总时长”包括做题、看解析、错题复盘和最后回顾；“真实考试时长”只用于仿真节奏，两者分开记录。学生给出固定题量时，先尊重题量，再说明预计所需时间；若题量和时长冲突，提供可完成的核心批次与可选扩展，不悄悄降低解释质量。

在没有学生历史速度时，可使用下列**估计起点**，之后依据实际作答调整。它们不是对学生速度或掌握程度的预测。

| 题型 | 中等难度作答 s（分钟） | 反馈／核对 r（分钟） |
| --- | ---: | ---: |
| 单选概念题 | 1.0 | 0.75 |
| 多选题 | 1.5 | 1.0 |
| 短追踪、计算或读代码 | 2.5 | 1.5 |
| 简答／短代码自评 | 4.0 | 2.0 |

简单题可把 s 乘 0.75，困难题乘 1.5；r 也应按解释或评分量表的实际长度调整，不能只计算点击答案的时间。长证明、长计算或完整编程任务单独估计，不套用“简答 4 分钟”。学生提供真实速度或考试节奏时优先使用。

设总时间 T，最后回顾 C，其余时间 E = T − C。采用以下默认分配并允许按学生情况调整：

- T ≤ 5：直接做已知薄弱点的诊断／速通；可插入 1 道口头检验，但不先减去 5 分钟导致零时间再强制出题。
- 5 < T < 45：最后回顾 C = min(3, 0.1 × T)，剩余时间根据考点多少安排少量诊断与复盘；适合时做迷你模考，说明它覆盖有限。
- T ≥ 45：C = 5；E 默认按练习 55%、模考 25%、错题复盘 20% 分配。

每一批题的预计成本为 Σ(sᵢ + rᵢ)。先按题型和考点蓝图挑题，直到下一题会超出该批预算；或用加权平均成本估算 n = floor(批次预算 ÷ 平均(s + r))，再用实际题型重新核算。先确定总量，再按范围和权重分配，不能机械地给每个概念固定 10 题；不要先固定“30 题”，再把任意时长写上去。

模考期间只显示作答计时，截止时间依据 Σsᵢ 或学生指定的真实考试时长；其解析 Σrᵢ 放在交卷后，但仍计入总学习预算。单独的错题复盘预算用于错因整理和再次尝试，避免把同一遍解析重复计入两项。

例如 T = 90 分钟、全为中等单选时，回顾 5 分钟，练习约 46.75 分钟、模考约 21.25 分钟、复盘约 17 分钟；按每题约 1.75 分钟，初估练习 26 题、模考 12 题，再依考点覆盖和难度修正。12 题的作答计时约 12 分钟，余下约 9 分钟用于交卷后的解析。这只是时间预算示例，不是所有课程的推荐题数。

出题前给学生一个简短方案：“按你这次 60 分钟、以读代码为主的范围，我预计安排 X 道练习、Y 道迷你模考、Z 分钟复盘；实际速度变化时可跳过扩展题。”普通方案无需等待额外批准。

若时间不足以覆盖全部考点，先覆盖明确高优先级和已知错误；列出未覆盖项。若题量很大，分批制作并保留独立 ID 和共同蓝图；不要将只有第一批的包称为完整题库。不要以“题量更多”替代代表性与解析质量。

## 4. 编写题目与解释

每道题至少检查：测什么、依据是什么、是否可在预算时间内作答、答案是否唯一或评分条件是否清楚、错误反馈是否能帮助纠正误解。

- 单选：题干提供足够条件，正确选项可独立推导；选项结构相近，避免长度或语法泄露答案。
- 多选：明确选择规则；按网页契约使用整题精确匹配，或在明确支持部分分时说明计分。不要暗示未实现的部分分。
- 追踪／计算：解释关键中间步骤，涉及语言行为时遵守课程版本；未定义、依实现而变或条件不全时写清前提。
- 简答：给出分点参考答案、必须出现的要点与常见错误；自评选项与参考标准相符。把自评分数和客观计分分开解释。
- 解释：先说理由，再点出主要干扰项对应的误区；不是把正确选项重复一遍。避免用“显然”“记住即可”掩盖推导。

每题关联可定位来源；结合多个来源的综合题可以关联多个，但不伪造引文。参考答案来自 AI 推导时要能自洽，并明确它不是教师提供的官方答案。

对重要公式、代码、数值和结论做一次独立核对：重新演算、追踪代码，或对照原文。若不能核实，标记待核实并排除确定计分。不要为了达到题量把歧义题加入模考。

为每个考点编写小型复习卡：一句核心规则、一个常见误区、必要的公式／代码片段、一个自检问题。卡片是离线薄弱点报告和速通的内容来源，必须先写好，页面不会自动调用模型生成解释。

## 5. 练习池与模考池

优先将独立题目分配到 practice 与 mock。确实需要共用时可标为 both，但向学生说明会重复；已见题的模考结果不当作独立未见测评。

给变体保留共同题族标识／关系（按数据契约表达）。同题换数字、换变量名或换选项顺序不等于新知识迁移。划分题池时以题族而非单个 ID 避免泄漏；若契约或来源无法表达题族关系，在编写阶段手动保证题族分组，并在包说明记录限制。

模考按范围和考试题型抽样。题库不足时提供小规模诊断，写清覆盖和独立性限制；不为模仿“正式考试”凭空补无来源知识。

## 6. 本地页面的学习闭环

练习提交后显示解释和来源；重复作答保留历史。错题本记录错误、未答和自评不确定的状态，按实现契约分别展示。已解决表示两次正确重做达到页面规则，不等于科学验证的长期掌握；再次错误应重新打开。

模考开始时固定题目和截止时间；交卷前隐藏解释，结束后统一反馈。刷新、切换标签页或重开不能增加时间；页面以固定截止时间判断是否到期。开始前说明实际题数和计时，包含共用题时明确标识。

进度保存在浏览器本地。提供导出 JSON 作为可迁移备份，导入时校验学习包和版本、题目 ID、记录格式；不要静默把不兼容历史绑定到新题。交付说明提醒学生换浏览器、清理存储或移动文件时应先导出。

离线报告根据记录和预先写好的复习卡汇总：考点覆盖、错误次数／尝试次数、仍未解决项、最近错误、可复习规则。少量数据使用“暂时薄弱／证据不足”，不能用任意阈值宣称“已掌握 90%”。展示自评来源，并把首次作答和反复练熟的表现区别说明。

速通内容优先取仍未解决的错点，控制为约 5 分钟可读完的长度，集中规则、易混对照、关键公式和检查动作；无错题时给覆盖范围内的核心概念回顾，并说明尚无错误证据。学习时长很短时，速通可作为主要交付而不是强制附加 5 分钟任务。进入最后 5 分钟或用户说不再出题时，停止新增题目，用“先回忆规则 → 看易混区别 → 回看判断步骤”进行回顾；主动回忆提示不是一轮新的计分考试。

## 7. 回收报告与继续学习

学生将导出的 Markdown 报告或进度 JSON 发回 AI 后，先确认学习包标识、材料版本和是否缺历史。使用已有记录分析，不要求学生重新回答完整问卷。

对每个优先薄弱点输出：证据题号／记录 → 具体误解 → 正确规则 → 一个纠错动作。只有错误答案不足以断定原因时，用一个短问题区分概念不清、计算失误或读题失误；不要给学生贴能力标签。

仍有学习时间且学生需要时，新增练习应针对已观察到的误解，并至少改变情境或推理步骤；变体照常标注。新题先不透露答案，学生作答后再反馈。迁移题的结果才可用于更新对迁移能力的判断，仍说明样本量和不确定性。最后 5 分钟以已有错误的概念解释、易混辨析和考试判断逻辑为主，不继续增加新题。

最后整理两份简短内容：一份按优先级排列的“还不会什么”，一份约 5 分钟可读完的考前速通。把待核实的课程说法单列；不将学习包的表现转换为没有依据的预测考分。若最后几分钟报告缺题号或知识点细节，先给按“客观错题 → 自评不会 → 未测范围”回看的可执行顺序，并标出信息不足；不要等待完整元数据才开始复习。即时速通先在对话交付，需下载保存时再生成零题复习卡 HTML。
