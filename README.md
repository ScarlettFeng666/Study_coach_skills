# 考试学习教练 · exam-study-coach

备考小队，出发啦！📚 这是一套已经设计好的备考对话，会一步步带你从准备资料走到刷题复盘。

**上传技能包并发送启动语后，就留在同一个聊天里，跟着 AI 的提问回答。** 它会依次了解：你准备什么考试、有哪些课件和例题，以及这次能学习多久，再制作一个可以下载的刷题网页。下载后用浏览器打开，就能练习、查看错题、进行模考，并复习薄弱点和考前 5 分钟重点。

**[📦 下载完整技能包 exam-study-coach.zip](https://github.com/ScarlettFeng666/Study_coach_skills/releases/latest/download/exam-study-coach.zip)** · **[📖 第一次使用指南](使用指南.md)** · **[📋 可复制的完整启动语](通用启动提示词.txt)**

只想先体验刷题功能？[下载 SWE113 演示网页](https://github.com/ScarlettFeng666/Study_coach_skills/releases/latest/download/SWE113-study-demo.html)，用浏览器打开即可。它是已有题目的演示，不会自动变成你自己课程的题库。

## 第一次用，照这四步来

1. **下载技能包。** 使用上方的完整 ZIP 下载链接。先找好手头的考试范围或 Study Guide、课件或笔记、历年题或课堂 quiz；没有某项资料也可以直接说明。
2. **交给 AI。** 选择能读取附件、生成可下载文件的 AI，新开一个聊天，上传整个 `exam-study-coach.zip`，然后复制下面的启动语发送。
3. **在同一个聊天里跟着回答。** AI 会先介绍这套对话怎么进行，再逐步问考试范围、课件、例题和本次学习总时间。按提示分批上传资料即可，不用自己先整理出知识点，也不用一次回答整套问卷。
4. **下载你的学习网页。** 现有资料收集完、缺项已说明后，AI 会规划题量并交付 `study.html`。把文件下载到电脑，用浏览器打开，开始刷题。聊天里的文件预览未必能运行全部交互。

上传技能 ZIP 后，复制这段发送：

```text
请读取附件技能包中的 SKILL.md，并按需读取它引用的配套文件，作为我的考试学习教练。

首次开场请先友好地说明：接下来我会在同一个聊天里，跟着你的提问，依次提供考试范围、课件、例题和本次学习总时间，最后得到一个可下载的刷题网页。
介绍后，只问当前第一个缺失的问题；已经提供的信息不要重复问。资料可以分批上传，缺少的资料请记录并说明。

请把做题、看解析和错题复盘一起计入我的时间预算，使用随包模板生成可下载、可离线打开的 study.html，包含练习、错题本、限时模考、薄弱点和考前 5 分钟速通。
如果不能读取文件或生成附件，请说明具体限制，不要声称已经完成。已有学习报告或只剩最后 5 分钟时，请直接接续复习。
```

正常的第一轮会先告诉你怎么参与，再问类似“你正在准备哪门考试？”的问题。接下来继续在原聊天里回答即可。时间指的是**本次可用的总学习时间**，包括做题、看解析和复盘；题量会随时间和题型变化，不一定是 30 题。

AI 无法读取 ZIP 时，按[使用指南第 2 步](使用指南.md#2-把技能交给-ai并发送启动语)解压并提供所需文件。只把 GitHub 链接粘给 AI，不能保证它会读到完整技能包。

## 生成之后，怎么学

先打开网页的 `06 资料与计划`，确认范围和来源说明，再按下面的顺序使用：

| 你想做什么 | 网页里怎么操作 |
| --- | --- |
| 练习并看解析 | 在 `01 练习` 作答后点 `核对答案`；重做同题时点 `再练一次` |
| 把错题练会 | 在 `02 错题本` 点 `重练这道题`；出错后连续答对两次才标为“已巩固”，历史仍保留 |
| 做一次限时检查 | 在 `03 限时模考` 选本场题数并开始，交卷后在模考记录点 `查看本场复盘` |
| 找到还需复习的内容 | 查看 `04 薄弱点` 的覆盖、错误记录和回忆提示；未测试内容不能据此判断掌握情况 |
| 临考再过重点 | 查看 `05 考前 5 分钟`，先回忆，再看规则和易混点；最多 6 个主题，是重点节选 |

模考时限由题包预设，开始后不能暂停。刷新或关闭网页不会停止计时；进行中在网页内切换到其他学习模式，确认离开会立即交卷，空题计错。简答题需要对照评分要点**自行评分**，与客观题正确率分开统计。

网页能离线整理学习记录和复习卡。要获得更深入的讲解、新变式题或重新整理考前总结，点 `学习报告 .md` 或 `学习报告 .json`，把导出的文件发回 AI，再告诉它你还剩多少时间。

例如：

```text
这是我的学习报告。我还剩 20 分钟，请按实际错误找出最需要复习的知识点，引用对应题号，解释概念边界，并安排少量针对性练习。
请区分客观题答错、简答自评不会和未测试内容；不能确定错因时请说明。
```

## 学习报告和进度备份，用途不同

| 按钮 | 用来做什么 |
| --- | --- |
| `学习报告 .md` / `学习报告 .json` | 上传给 AI，分析已作答题目、作答、参考答案及来源状态，继续讲解与复盘 |
| `备份进度 JSON` | 保存作答、错题和练习草稿；下次打开**相同题包、相同内容版本**的 HTML，用 `恢复进度` 导入 |
| `导出这份速通清单` | 单独保存考前 5 分钟重点，方便阅读 |

建议每次学完，同时保存 **HTML 原文件和进度备份**。本机记录不是云同步，换设备、换浏览器、移动文件或清理浏览器数据，都可能影响保存。AI 修改或重新生成题库后，旧备份可能无法恢复。学习报告不能代替进度备份。

## 来源和使用边界

这套流程源于一次真实备考实践，提取的是“明确范围、提供资料、按时间规划、刷题、错题复盘”的方法，不限定课程、题量或单选题型。

演示沿用该次 SWE113 备考中提供的 30 道示例题。原 PPT 未随项目提供，因此课件引用及页码标为**未核验**。演示练习和模考共用同一题库，见过题后的成绩不能当作陌生题测评；为自己的课程生成时，应优先使用独立题池。

题目与参考答案仍需结合课程资料核对，网页不会自动验证学科答案。材料不足时，AI 应说明哪些属于通用练习、哪些还无法核验。

生成后的网页在本机运行，不调用 AI 或外部 API，也不会上传学习资料。向 AI 上传课件与报告时，资料如何处理取决于你选择的平台。不同 AI 的附件读取、文件生成和执行能力有差别，不能保证全部原生支持这套技能或产生完全相同的结果。

### 手动构建

需要 Python 3，构建器仅用标准库。在解压后的技能目录执行：

```text
python scripts/build_study_pack.py --data examples/swe113-demo.json --validate-only
python scripts/build_study_pack.py --data examples/swe113-demo.json --output examples/SWE113-study-demo.html
```

为其他考试生成时，让 AI 按 `references/data-contract.md` 写新的 JSON，再将 `--data` 指向它。结构验证检查数据约定，不判断学科答案对错；请另外核对题目与课件是否一致。

### 平台兼容与替代交付

如果平台原生支持 Agent Skills，按该平台方式载入整个文件夹；仅复制 `SKILL.md` 会丢失模板、数据约定和构建器。不原生支持时，可以将它作为一组工作指令和模板提供给 AI。

AI 不能解压 ZIP 时，先本地解压，再提供 `SKILL.md`、`references/learning-workflow.md`、`references/data-contract.md`、`assets/study-template.html` 和 `scripts/build_study_pack.py`。附件不保留目录时，请同时说明各文件的原路径。

AI 只能处理文字时，可让它按数据约定生成 JSON，然后自行用构建器生成 HTML；也可让它将完整模板中的唯一标记替换成安全转义后的 JSON，输出完整 HTML 代码，按[使用指南](使用指南.md)手动保存。后者没有自动验证，必须自行打开验收。不能完成读取、构建或生成附件时，AI 应明确说明，不能声称已经生成或测试成功。
